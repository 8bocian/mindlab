Przejścia pętli (warstwy, które model wykonuje kilka razy):

      

    

    
    
Środkowe warstwy (ok. ⅓–½ głębokości) zwykle dają najczystszy efekt. Wiele warstw naraz kumuluje efekt, więc wtedy zmniejsz siłę.

Logit lens: co przewidziałaby każda warstwa

    

    
Wiersze to warstwy (·p = przejście pętli), kolumny to ostatnie tokeny. Jasność komórki to pewność. Na dole (zielono) token, który model faktycznie napisał. Kliknij token w rozmowie, żeby go przypiąć.
